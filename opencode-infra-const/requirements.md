# OpenCode-Link — 要件定義書

## 1. プロジェクトの目的

OpenCode をフォークし、Codex ライクな GUI クライアント（OpenCode-Link）を構築する。
PC とスマホの両方からブラウザ経由でアクセスし、同一のセッションを共有・操作できる環境を実現する。

## 2. 対象ユーザー

- 自宅の PC で OpenCode を使っている人
- 外出先からスマホで同じセッションにアクセスしたい人
- ターミナルやファイル操作を含めた開発作業を Web 上で完結させたい人

## 3. 機能要件

### 3.1 必須機能（MVP）

| # | 機能 | 説明 |
|---|---|---|
| 1 | セッション一覧表示 | サイドバーにセッション一覧を表示 |
| 2 | セッション切替 | クリックでセッションを切り替え |
| 3 | チャット UI | メッセージの送受信、ストリーミング表示 |
| 4 | モデル切替 | プロバイダ×モデルを簡単に切替 |
| 5 | ターミナル表示 | チャット下部にターミナルを表示 |
| 6 | ファイル参照 | アプリ内でファイルを参照・編集 |
| 7 | スマホ対応 | レスポンシブ/タッチ操作対応 |
| 8 | PWA | ホーム画面追加対応 |

### 3.2 高度機能

| # | 機能 | 説明 |
|---|---|---|
| 9 | エージェント管理 | サブエージェントの on/off、モデル割り当て |
| 10 | 使用量ダッシュボード | プロバイダ別・モデル別のトークン/コスト |
| 11 | HTML アノテーション | レビュー時に HTML にラベルを張って指示 |
| 12 | プラグイン管理 | アプリ内でプラグインの有効/無効切替 |

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| パフォーマンス | 操作応答 1 秒以内 |
| 信頼性 | サーバー停止時は再接続を自動試行 |
| セキュリティ | Tailscale 経由でのみ外部アクセス |
| 拡張性 | 既存の OpenCode プラグイン機構を維持 |
| 保守性 | OpenCode のアップストリーム追従が容易 |

## 5. 制約条件

- OpenCode の既存コードベースをフォークして改修
- UI フレームワークは SolidJS を維持
- パッケージマネージャは Bun を維持
- デスクトップアプリ（Electron）は不要
- Codex のピクセルパーフェクト再現は不要
