```

├──────────┬───────────────────────────────────────┬─────────────┤
│          │                                       │             │
│ サイドバー│              チャット                  │  右パネル   │
│          │                                       │             │
│ Search   │                                       │  Context    │
```

## 2. サイドバー

### 2.1 通常表示

- 幅: 280px
- 背景: `--surface-base`
- 区切り線: 右 1px `--border-weak-base`

### 2.2 セッションアイテム

```
[●] Session Title                    Model Name
     provider/modelID                Time
```

## 3. トップバー

### 3.1 要素

| 位置 | 要素 |
|---|---|
| 左 | メニューボタン、DEV バッジ |
| 中央 | モデルセレクター、ファイル検索 |
| 右 | ターミナルトグル、レビュートグル、ファイルツリートグル |

### 3.2 モデルセレクター

```
[Icon] MiMo V2.5 Pro ▼
```

## 4. チャット画面

### 4.1 ユーザーメッセージ

- 右寄せ
- 背景: `--surface-base`
- 枠線: 1px `--border-weak-base`
- 角丸: 6px
- 最大幅: 82%

### 4.2 アシスタントメッセージ

- 左寄せ
- 背景: `--surface-weak`
- 枠線: 1px `--border-weak-base`
- 角丸: 8px
- 最大幅: 85%
- コードブロック: 背景 `#1e1e1e`

## 5. プロンプト入力欄

### 5.1 レイアウト

- 下部固定
- 高さ: 可変（最大 200px）
- 背景: `--surface-raised-base`

### 5.2 要素

- 添付ファイルボタン
- テキストエリア
- 送信ボタン
- モデルセレクター

## 6. ターミナルパネル

### 6.1 レイアウト

- チャット下部
- 初期高さ: 200px
- リサイズ可能

### 6.2 要素

- タブ
- ターミナル出力
- コマンド入力欄

## 8. モバイルレイアウト

### 8.1 画面幅 < 768px

- サイドバー: 非表示、スワイプで表示
- 右パネル: 非表示
- トップバー: 簡易表示
- チャット: 全幅
- ターミナル: 全幅モーダル

### 8.2 ナビゲーション

- 下部タブバー（チャット/ターミナル/設定）
- スワイプでサイドバー表示
