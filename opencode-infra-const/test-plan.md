# OpenCode-Link — テスト計画書

## 1. テスト方針

| レベル | 内容 | 実施者 |
|---|---|---|
| 単体テスト | コンポーネント/SDK 関数 | 開発者 |
| 結合テスト | API + UI の連携 | 開発者 |
| E2E テスト | ブラウザ操作フロー | 開発者 |
| 受け入れテスト | 実際の使用感確認 | ユーザー |

## 2. 単体テスト

### 2.1 対象

- `sidebar-items.tsx` のセッション表示
- `session-header.tsx` のモデルセレクター
- `message-part.css` のスタイル
- `@opencode-ai/sdk` の API 呼び出し

### 2.2 ツール

- Vitest（Vite プロジェクトに統合）
- `@solidjs/testing-library`

## 3. 結合テスト

### 3.1 テストケース

| # | ケース | 期待結果 |
|---|---|---|
| 1 | API サーバー起動 → Web UI 接続 | セッション一覧が表示される |
| 2 | セッション選択 → チャット表示 | メッセージが表示される |
| 3 | モデル切替 → メッセージ送信 | 新しいモデルで応答 |
| 4 | プロバイダ設定保存 → 接続確認 | プロバイダが有効化 |
| 5 | エージェント on/off → 挙動確認 | エージェントが有効/無効 |

### 3.2 コマンド

```bash
bun test
```

## 4. E2E テスト

### 4.1 ツール

- Playwright
- Tauri の WebView テスト（必要に応じて）

### 4.2 シナリオ

| # | シナリオ | 手順 |
|---|---|---|
| 1 | ログインからチャット | 1. URL オープン 2. 認証 3. セッション作成 4. メッセージ送信 |
| 2 | スマホレイアウト | 1. スマホ幅にリサイズ 2. サイドバー表示 3. チャット操作 |
| 3 | PWA 起動 | 1. ホーム画面追加 2. オフライン表示 3. オンライン復帰 |

## 5. 受け入れテスト

### 5.1 チェックリスト

| # | 項目 | 確認 |
|---|---|---|
| 1 | PC ブラウザでセッションが表示される | ⬜ |
| 2 | スマホブラウザでセッションが表示される | ⬜ |
| 3 | モデル切替が 2 タップ以内 | ⬜ |
| 4 | 使用量が 2 タップで確認できる | ⬜ |
| 5 | ターミナルが表示/非表示切替可能 | ⬜ |
| 6 | ファイルがアプリ内で参照できる | ⬜ |
| 7 | Tailscale 経由で外部からアクセス可能 | ⬜ |
| 8 | 操作応答が 1 秒以内 | ⬜ |

## 6. パフォーマンステスト

| 項目 | 目標 |
|---|---|
| 初回ロード | 3 秒以内 |
| セッション切替 | 500ms 以内 |
| メッセージ送信 | 1 秒以内（応答開始） |
| ターミナル出力 | リアルタイム |

## 7. セキュリティテスト

| 項目 | 確認内容 |
|---|---|
| 認証 | パスワードなしで API にアクセスできない |
| CORS | 許可されていないオリジンからのアクセスをブロック |
| Tailscale | 外部ネットワークから直接アクセスできない |

## 8. リグレッションテスト

- OpenCode アップストリーム更新後
- 新機能追加後
- 設定ファイル変更後
