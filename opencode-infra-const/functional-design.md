# OpenCode-Link — 機能設計書

## 1. セッション管理

### 1.1 セッション一覧

- **表示場所**: 左サイドバー
- **表示情報**:
  - セッションタイトル
  - 使用モデル名（provider/model）
  - 最終更新日時
  - 未読/エラー/作業中インジケータ
- **操作**:
  - クリックでセッション切替
  - 長押し/右クリックでメニュー
  - 検索フィルタ
  - 新規作成

### 1.2 セッション詳細

- **表示場所**: 中央ペイン
- **構成**:
  - トップバー（モデル選択、ターミナルトグル、レビュートグル）
  - メッセージタイムライン
  - プロンプト入力欄
  - ターミナルパネル（下部）
  - コンテキストパネル（右部）

## 2. モデル管理

### 2.1 モデル切替

- **トリガー**: トップバーのモデルボタン
- **UI**: ドロップダウン（プロバイダ別グルーピング + 検索）
- **反映**: 即座に現在のセッションに適用

### 2.2 モデル情報表示

- モデル名
- プロバイダ名
- 料金情報
- 対応モダリティ（text/image/audio）

## 3. プロバイダ管理

### 3.1 プロバイダ一覧

- **表示場所**: 設定 > プロバイダ
- **表示情報**:
  - プロバイダ名
  - 接続状態
  - API キー設定状態
  - 有効/無効トグル

### 3.2 API キー設定

- マスク入力
- 検証ボタン
- 保存時の暗号化

## 4. エージェント管理

### 4.1 エージェント一覧

- **表示場所**: 設定 > エージェント
- **表示情報**:
  - エージェント名
  - 種別（primary/subagent）
  - 有効/無効トグル
  - 割り当てモデル

### 4.2 エージェント詳細

- 説明編集
- パーミッション設定
- モデル割り当て

## 5. ターミナル

### 5.1 レイアウト

- チャット下部に分割表示
- 高さリサイズ可能
- 表示/非表示トグル

### 5.2 機能

- コマンド実行
- 出力表示
- タブ切替

## 6. 使用量ダッシュボード

### 6.1 表示情報

- 期間別トークン使用量
- プロバイダ別コスト
- モデル別コスト
- ツール使用頻度

### 6.2 UI

- 折れ線グラフ
- 円グラフ
- テーブル表示
- 期間切替（今日/7日/30日/全期間）

## 7. ファイル参照

### 7.1 ファイルツリー

- プロジェクト内ファイルの表示
- ファイルクリックでエディタ表示
- 検索機能

### 7.2 コードエディタ

- シンタックスハイライト
- 行番号
- 折りたたみ

## 8. HTML アノテーション

### 8.1 機能

- HTML レンダリング結果上にマーカー配置
- マーカーにテキスト指示を紐付け
- 指示をプロンプトとして送信

### 8.2 UI

- マーカーツール
- ラベル編集
- 送信ボタン
