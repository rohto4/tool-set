クイックヘルプ

編集作業で頻繁に使う操作をまとめています。

  • Ctrl/Cmd+Z: 元に戻す
  • Ctrl/Cmd+Y または Ctrl/Cmd+Shift+Z: やり直す
  • Ctrl/Cmd+A: 全選択
  • Ctrl/Cmd+C / X / V: コピー、切り取り、貼り付け
  • Ctrl/Cmd+D: 複製
  • Delete: 選択ノードまたは接続を削除
  • 矢印、Shift+矢印: 微移動、大きく移動
  • Ctrl/Cmd+[ と Ctrl/Cmd+]: 前後移動
  • Space+drag または中ボタンドラッグ: ハンドパン
  • キャンバスをドラッグ: 範囲選択
  • 接続モードを有効化してからノードを順にクリック: 接続を作成
  • Esc: ヘルプや選択を閉じる
