Quick Help

Demo-ready shortcuts and actions.

  • Ctrl/Cmd+Z: Undo
  • Ctrl/Cmd+Y or Ctrl/Cmd+Shift+Z: Redo
  • Ctrl/Cmd+A: Select all
  • Ctrl/Cmd+C / X / V: Copy, cut, paste
  • Ctrl/Cmd+D: Duplicate
  • Delete: Delete selection or edge
  • Arrows: Nudge, Shift+Arrows: fast nudge
  • Ctrl/Cmd+[ and Ctrl/Cmd+]: Layer order
  • Drag on canvas: Marquee select
  • Connect mode: click source then target
