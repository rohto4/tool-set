UI Kit Canon

`site/ui-kit.html` を見た目正本として、文字サイズ、ノード寸法、余白、角丸、色、パレット、 インスペクター、ラベル、注釈、領域コンテナの基準を実画面サイズで並べています。

操作改善の優先順位

このセッションで明文化する次の実装順です。ビュー操作の基盤を先に固め、注記系はその後に続けます。

1 ハンドパン

広い図面を扱う土台。カメラ座標系を先に持たせる。

2 背景グリッド追従

ハンドパンと同じビューポート変換に載せて違和感を消す。

3 テキストボックス追加

注釈レイヤーを先に実装し、説明文や補足の置き場所を作る。

4 領域塗り

領域コンテナと注釈の表現を見てから塗りルールを決める。
