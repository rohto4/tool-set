# Session 02 Prompt

## Name

UI キット整備と操作改善の下準備

## Focus

`ui-kit.html` を正本に、構成図エディタの見た目ルールと次段の操作改善方針を固める。主対象は `site/ui-kit.html`、`site/styles.css`、必要最小限の `site/index.html` と `site/app.js`。

## Avoid

- CLI / core 分離
- テスト導入
- 大規模なデータモデル再設計

## Done When

- `site/ui-kit.html` に主要部品の見本が並んでいる
- フォントサイズ、部品寸法、余白、角丸、色の基準が実画面ベースで見える
- 次に実装する操作改善の優先順位が明文化されている
- 本体画面側が UI キット方針と明確に矛盾しない状態になっている

## Start Prompt

このセッションでは UI キット整備と操作改善の下準備に集中してください。`site/ui-kit.html` を新しい見た目正本として扱い、文字サイズ、ノード寸法、余白、角丸、パレット、インスペクター、ラベル、テキスト、領域コンテナなどの見本を並べてください。本体 `index.html` はそのルールに寄せる範囲でだけ調整し、背景グリッド追従、ハンドパン、領域塗り、テキストボックス追加などの次段アプローチも整理してください。CLI / core 分離やテスト導入はこのセッションでは行わないでください。
