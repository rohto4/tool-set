# Session 06 Prompt

## Name

レイアウト / 選択 / 接続高度化

## Focus

selection、alignment、routing、snap、layout の体験品質を改善する。対象は interaction と layout のロジック。

## Avoid

- DSL 文法の大拡張
- 無関係なデータモデル再設計

## Done When

- 複数選択、接続、整列、配置補助の手触りが現状より明確に改善している
- 回帰しやすい形でロジックが整理されている

## Start Prompt

このセッションでは、selection、alignment、routing、snap、layout の体験品質を改善してください。対象は interaction と layout のロジックで、DSL 文法の大拡張は同時に行わないでください。複数選択、接続、整列、配置補助の手触りを一段上げることが目的です。
