# Session 07 Prompt

## Name

DSL / バリデーション強化

## Focus

import/export DSL の強化と validation に集中する。parser、serializer、validator を主対象とする。

## Avoid

- UI の全面改修
- 画面レイアウト変更の同時進行

## Done When

- 不正入力を検出できる
- エラー理由を出せる
- 安定した入出力往復ができる

## Start Prompt

このセッションでは、import/export DSL の強化と validation に集中してください。parser、serializer、validator を主対象とし、不正入力へのエラー表示と round-trip の安定性を高めてください。UI の全面改修は避け、テキスト入出力の堅牢性を上げることを優先してください。
