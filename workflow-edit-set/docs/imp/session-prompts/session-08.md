# Session 08 Prompt

## Name

設定 / 右ペイン / 検索整理

## Focus

設定 UI、モーダル整理、右ペイン再編、検索強化、ショートカット管理の整理に集中する。

## Avoid

- コア state の再設計
- CLI / core 層の別テーマ混在

## Done When

- 右ペインと設定系の役割が明確になっている
- 検索やショートカットの扱いが分かりやすくなっている

## Start Prompt

このセッションでは、設定 UI、モーダル整理、右ペイン再編、検索強化、ショートカット管理の整理に集中してください。コア state の再設計は避け、情報構造と操作導線を改善してください。
