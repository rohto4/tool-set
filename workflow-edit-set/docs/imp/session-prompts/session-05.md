# Session 05 Prompt

## Name

コンポーネント定義拡張

## Focus

コンポーネント辞書、カテゴリ、アイコン対応を大幅に拡張する。主対象は定義ファイルとアイコン資産。

## Avoid

- コアロジックの再改修
- 無関係な UI 再設計

## Done When

- 部品数が大きく増えている
- 部品追加をデータ駆動で継続しやすい形になっている
- AWS 風の選択肢が十分に増えている

## Start Prompt

このセッションでは、コンポーネント辞書、カテゴリ、アイコン対応を大幅に拡張してください。主対象は定義ファイルとアイコン資産で、コアロジック再改修は最小限にしてください。部品追加をデータ駆動で継続しやすい形に整え、AWS 風の選択肢を増やしてください。
