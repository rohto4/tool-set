# Project Operations

## 運用の要点

- この PJ は `workflow-edit-set` 配下だけで完結させる。
- 文書の正本は常に `docs/` 配下に置く。
- 仕様未確定の案は `spec/` ではなく `condi-ref/` に置く。
- 実装した内容や変更理由は `imp/` に残す。

## ディレクトリ運用

- アプリ本体: `site/`
- 文書: `docs/`
- 将来の素材置き場: `assets/`

## 変更時の更新対象

- 仕様変更: `docs/spec/architecture-editor-spec.md`
- 運用変更: この文書
- 大きな実装変更: `docs/imp/implementation-log.md`
